# Approved Materials Catalog

Approved fabrics for standard procurement without additional review:
cotton twill (200-320 gsm), organic cotton jersey (180-260 gsm), linen blend
(150-240 gsm), recycled polyester fleece (240-360 gsm).

Any material outside these families or gsm ranges is a non-catalog item and must be
flagged for sourcing review before the RFQ is sent to suppliers.

Each approved material maps to a supplier catalog entry (for example organic cotton
jersey maps to MAT-0042). Record the catalog code on the RFQ line item.
